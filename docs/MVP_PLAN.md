# MVP Plan

## Objective

Publish a lightweight English-language affiliate MVP that tests whether Pinterest traffic can move from SaaS comparison content to official vendor clicks.

## Scope Limit

- 1 Astro static site
- 5 articles
- 25 Pinterest pin concepts
- 3 initial affiliate candidates
- Lightweight analytics plan
- No database, Docker, crawler, local image generation, or heavy JavaScript

## Funnel

Pinterest pin -> English article -> official SaaS click -> affiliate signup or sale after approval.

## 30-45 Day Success Signals

- Pinterest impressions
- Pinterest outbound clicks
- Website visits
- Affiliate CTA clicks or affiliate dashboard clicks
- Signups, trials, paid conversions, or commission where available

## Cloudflare Pages

- Build command: `npm run build`
- Output directory: `dist`
- Static output: yes
- Domain and DNS changes require human approval.
